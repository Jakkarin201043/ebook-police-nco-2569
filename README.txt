บน iPad: เปิดลิงก์ใน Safari -> ปุ่มแชร์ -> "เพิ่มไปยังหน้าจอโฮม" -> เปิดจากไอคอน (อ่านออฟไลน์ได้หลังเปิดครั้งแรก)

Upload this whole folder to any HTTPS static host (service workers need HTTPS or localhost).
